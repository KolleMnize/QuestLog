# FrontEnd

I want a Home Page called **"Tavern"** – it will be empty at first.

--- 

I want a **Structure Page** ("Campaign Map").

I want to create a new node (without a parent):

- At the top of the page, there is a button labeled **"Add new Adventure"**.
- When pressed, a new node without a parent is created with the name **"new Adventure"**.

For now, it will be a simple nested list.  
A single entry (row) should have the following functions:

- **Rename node** → Text field (name is updated when leaving the field)
- **Toggle active status** → Radio button (status is applied on trigger)
- **Add child (Quest)** → Button (creates a new node as a child of the current node)

A **radio button in the header** allows selecting whether to display active, inactive, or all nodes.

---

On the Home Page, I want a kind of **Dashboard**:

- Overview of the number of **active quests** and **inactive quests**
- **Nesting distribution**
  - A diagram with a curve showing, e.g., 1× level 1, 3× level 2, 2× level 3
  - Calculated variable in **Signal Store**

- **Sunburst Diagram** with filter options for active status & breadcrumb
  - Calculated variable in **Signal Store**
