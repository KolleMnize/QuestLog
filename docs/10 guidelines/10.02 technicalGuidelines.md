# authoritative business logic and client responsibilities

## core principles
Business truth is calculated in the backend.
The client may mirror it — but must never define it.

All business-critical computations are owned and enforced by the server (the backend).
The frontend may perform temporary or preview calculations for user experience purposes, but it is never the authoritative source of truth.

## typical real-world scenario
### Backend Responsibilities
- Calculates TotalAmount
- Persists TotalAmount
- Validates Items
- Enforces all business rules

The backend is the single authoritative source for financial and business-relevant data.

### Frontend Responsibilities
- Temporarily calculates TotalAmount for live user feedback
- Displays a preview during editing
- Uses the backend-calculated value after receiving the response

The frontend calculation exists solely for usability and responsiveness.

### Important Clarification

Both sides may implement the same formula.
However, only the backend result is authoritative.

All business logic must ultimately be validated and recalculated server-side to ensure consistency, integrity, and security.
